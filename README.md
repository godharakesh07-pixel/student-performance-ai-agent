# 🎓 Student Performance Prediction using Machine Learning

A beginner-friendly machine learning project that explores student data and uses a Decision Tree Classifier to predict student performance.

## 📌 Project Overview

The goal of this project is to learn how machine learning can be used to analyze student-related data and predict a performance category based on the available features.

## ✨ Features

* Create and prepare a student dataset using Pandas.
* Split data into training and testing sets.
* Train a Decision Tree Classification model.
* Evaluate model performance using accuracy.
* Practice a basic end-to-end machine learning workflow.
